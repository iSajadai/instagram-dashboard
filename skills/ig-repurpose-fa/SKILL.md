# ig-repurpose-fa

یه محتوای بلند خوب چهار تا شش تا پست توشه. بیشتر آدم‌ها یکی درمیارن و بقیه رو دور می‌ریزن.

## ورودی

ترنسکریپت، مقاله، خبرنامه، اسکریپت، خلاصهٔ یه تماس، لایو، یا پست‌های کانال تلگرام. اگه کاربر آدرس داد و این سشن ابزار ترنسکریپت داره، استفاده کن؛ وگرنه بخواه بچسبونه. قبل از اینکه چیزی دربیاری، کلش رو بخون.

اگه منبع ویدیوییه که مال خود کاربره، فایلش رو هم بخواه. ریلی که روی فیلم خودش ساخته شده از ریلی که همون حرف‌ها دوباره خونده شده بهتره.

## دربیار، خلاصه نکن

خلاصهٔ یه ویدیو ریل نیست. هیچ‌کس خلاصه نمی‌خواد. محتوا رو بگرد و چیزهایی که رو پای خودشون می‌ایستن رو بکش بیرون، با کلمات خود منبع:

| چی | یعنی |
| --- | --- |
| **ادعاها** | هر جمله‌ای که یه بحث راه می‌ندازه |
| **عددها** | هر رقم، هزینه (تومن، دلار)، مدت، درصد |
| **داستان‌ها** | هر لحظه‌ای که یه آدم، یه صحنه و یه هزینه داره |
| **سازوکارها** | هر «روش کارش در واقع اینه که…» |
| **اشتباه‌ها** | هر اعتراف به چیزی که خراب شد |
| **جمله‌ها** | هر جمله‌ای که همین‌جوری قابل نقل‌قوله |

قبل از نوشتن هر چیزی، چیزهایی که پیدا کردی رو با تعداد فهرست کن. اگه محتوا کمتر از چهار تا مورد داره، لاغره، و چهار پستی که ازش چلونده بشه هم لاغر می‌شه. بگو.

## بعد فرمت هر مورد رو انتخاب کن

همه‌چیز ریل نیست.

- **ادعا، اشتباه، داستان** ← ریل. صدا و صورت لازم دارن.
- **سازوکار، فهرست شماره‌دار** ← کاروسل. باید دوباره خونده بشن.
- **یه جملهٔ قابل نقل** ← یه فریم استوری، نه پست.

## بعد هفته رو بساز

هر مورد یه پست می‌شه و هر پست کاملاً رو پای خودش می‌ایسته. بیننده منبع رو ندیده و هیچ‌وقت هم نمی‌بینه. هیچ‌وقت ننویس «همون‌طور که تو ویدیوی آخرم گفتم». پست خود چیزه.

به هر کدوم یه فرمول هوک از ۲۶ فرمول فارسی بده و متنوعشون کن. پنج پست از یه منبع با یه شکل هوک شبیه کارخونهٔ محتوا خونده می‌شه، چون هست.

```bash
python3 ~/.claude/skills/ig-fa-tools/fa_tools.py formulas
```

اگه منبع ویدیوی خود کاربره، **از فیلم واقعی استفاده کن**. تیکه‌ای که حرف رو زده، با واکنش واقعی توش، همیشه از ضبط دوباره بهتره. روی جمله ببُر، نه روی نفس.

ترتیب هفته (از شنبه): قوی‌ترین ادعا اول، داستان وسط هفته، سازوکار آخر، وقتی کسایی که قبلی‌ها رو دوست داشتن منتظرشن.

## خروجی

```
منبع: «چرا جلسهٔ معارفه رو تعطیل کردیم» (پادکست ۴۲ دقیقه، حدود ۶٬۵۰۰ کلمه)

پیدا شد  ۵ ادعا، ۹ عدد، ۳ داستان، ۴ سازوکار، ۲ اشتباه، ۷ جملهٔ قابل نقل

هفته
یکشنبه    ریل     #۲  این کارو نکن        جلسهٔ معارفه رو تعطیل کن
                                          از دقیقهٔ ۱۴:۲۰ استفاده کن، آخرش می‌خنده
دوشنبه    کاروسل  کپشن کار B             فرم ۴ سؤالی که جای جلسه رو گرفت
چهارشنبه  ریل     #۲۱ شروع از وسط ماجرا  «…و نُه روز بعد پولشو پس خواست»
جمعه      ریل     #۵  کوتاه‌شدن زمان       هفته‌ای ۶ ساعت برگشت، با پاک کردن یه لینک

بگو «یکشنبه رو بنویس» تا پیش‌نویسش کنم.
```

بعد، به درخواست، یکی‌یکی پیش‌نویس کن، هر کدوم از `/ig-reel-fa` و `/ig-human-fa`. چهار اسکریپت تموم‌شده رو یه‌جا نریز. همه‌شون شبیه هم می‌شن و کاربر هیچ‌کدومو ضبط نمی‌کنه.

عددی که تو منبع نیست رو اضافه نکن. اگه پستی عدد لازم داره و منبع نداره، `{{عدد خودت}}` بذار و بگو. هیچی پست نمی‌شه.
