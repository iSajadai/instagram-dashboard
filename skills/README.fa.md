# بستهٔ اسکیل اینستاگرام فارسی (instagram-agent-fa)

۱۳ اسکیل Claude Code برای کریتورهای فارسی‌زبان: ریل، کپشن، کاروسل، استوری، پروفایل، برنامهٔ هفته، تحقیق وایرال، انسانی‌سازی متن، کامنت، جواب کامنت، دایرکت، بازنشر و کالبدشکافی آمار. ترجمهٔ تحت‌اللفظی نیست؛ برای فارسی و مخاطب ایرانی بومی شده: ۲۶ فرمول هوک فارسی، روبریک ۱۲ بخشی پروفایل، لحن محاوره با نیم‌فاصلهٔ درست، رقم فارسی، تومن، هفتهٔ شنبه‌به‌جمعه و ساعت تهران.

## نصب

**روش ۱: کپی دستی**

```bash
cp -r skills/ig-*-fa ~/.claude/skills/
cp -r skills/ig-fa-tools ~/.claude/skills/
mkdir -p ~/.claude/instagram
cp templates/voice.md ~/.claude/instagram/voice.md
```

**روش ۲: پلاگین**

```
/plugin marketplace add iSajadai/instagram-dashboard
/plugin install instagram-agent-fa
```

ابزار `fa_tools.py` فقط به پایتون ۳ نیاز داره و هیچ کتابخونهٔ اضافه‌ای نمی‌خواد.

## شروع

۱. اول `~/.claude/instagram/voice.md` رو پر کن، یا سه تا از ریل‌هات رو به Claude بده و بگو «از روی اینا voice.md منو بنویس».
۲. بعد همین‌جوری فارسی درخواست بده؛ اسکیل درست خودش فعال می‌شه:

| بگو | اسکیل |
| --- | --- |
| «یه ریل بنویس دربارهٔ…»، «هوک بده» | `ig-reel-fa` |
| «کپشن بنویس»، «هشتگ بده» | `ig-caption-fa` |
| «اینو کن کاروسل» | `ig-carousel-fa` |
| «امروز استوری چی بذارم» | `ig-story-fa` |
| «بایومو درست کن»، «به پیجم نمره بده» | `ig-profile-fa` |
| «هفته‌مو برنامه‌ریزی کن» | `ig-plan-fa` |
| «الان تو حوزه‌م چی جواب می‌ده» | `ig-viral-fa` |
| «انسانیش کن»، «ماشینی به نظر می‌رسه؟» | `ig-human-fa` |
| «زیر این پست کامنت بذار» | `ig-comment-fa` |
| «جواب کامنتامو بنویس» | `ig-reply-fa` |
| «به این دایرکت بده» | `ig-dm-fa` |
| «از این پادکست ریل دربیار» | `ig-repurpose-fa` |
| «آمارمو تحلیل کن» | `ig-audit-fa` |

یا مستقیم صداش کن: `/ig-reel-fa ایده‌ت`.

## چیزهایی که این بسته نمی‌کنه

هیچ‌وقت پست، کامنت، لایک، فالو یا دایرکت نمی‌فرسته؛ وارد اکانتت نمی‌شه و رمز نمی‌خواد؛ اسکرپ نمی‌کنه. هیچ عدد یا نتیجه‌ای به اسمت نمی‌سازه و جاش `{{عدد خودت}}` می‌ذاره. بررسی انسانی بودن متن چند قاعدهٔ محلیه، نه GPTZero یا ابزارهای مشابه.

فایل‌هایی که ساخته می‌شن: `~/.claude/instagram/voice.md`، `swipe.md`، `plan.md` و `log.md`.
